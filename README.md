# 🎓 LMS Future Academy - Learning Management System (MVP)

A lightweight, centralized Learning Management System built specifically for our college cohort. Designed as a faster, more organized, and premium alternative to Google Classroom, focusing on seamless material distribution and assignment tracking.

## 🚀 Tech Stack

### Backend (API)

- **Framework:** [NestJS](https://nestjs.com/)
- **Language:** TypeScript
- **Database:** PostgreSQL
- **ORM:** TypeORM
- **API Documentation:** Swagger / OpenAPI
- **Deployment:** Render

### Frontend (Client)

- **Framework:** React / Next.js _(Update if using something else)_
- **Styling:** Tailwind CSS
- **Deployment:** Vercel / Netlify

## ✨ Core Features

- **🛡️ Role-Based Access:** Dedicated interfaces and permissions for Students, Doctors, and Admins.
- **📚 Centralized Materials:** Doctors can seamlessly upload and organize course materials (PDFs).
- **📝 Task Management:** End-to-end assignment workflows (Creation, Submission, Tracking).
- **⏳ Deadlines Dashboard:** Visual tracking for upcoming tasks and missing submissions for students.
- **📊 Auto-Reports:** Excel export feature for doctors to easily track student submissions.
